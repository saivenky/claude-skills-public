# Tech Lead

Sets the posture for the **rest of the session**: read [`leading`](../leading/SKILL.md) and follow it. The EM stays in the room, dropping items on the board as they occur.

- **Bare** — confirm the posture in one line, then wait for the first item.
- **With work** — that work is the first item on the board.

An item that ships code follows [`ship`](../ship/SKILL.md)'s technical steps for that item: its own worktree, slices, validation, and landing — so parallel items never race on one git index. Each lands as **its own commit**, scoped to that item alone. A one-line edit you already hold in context may go in place.

Several features at once is just several items on the board.
